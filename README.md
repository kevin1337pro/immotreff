# immotreff

Responsive Immobilien-Suchseite für Bottrop und das Ruhrgebiet. Die statische Seite benötigt keinen Build-Schritt und kann direkt über GitHub Pages veröffentlicht werden.

Die enthaltenen Beispielangebote, Objektbilder und Kontaktdaten stammen von [immostaff.de](https://www.immostaff.de/). Die Daten sind eine Momentaufnahme und werden nicht automatisch aktualisiert. Die Kartenmarkierungen zeigen ungefähre Stadtteillagen. Vor einem produktiven Einsatz sollten Aktualität, Nutzungsrechte und Kontaktdaten überprüft werden.

Die Karte verwendet Leaflet und Kartenmaterial von OpenStreetMap und CARTO.
